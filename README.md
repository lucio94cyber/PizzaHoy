# 🍕 PIZZAHOY
### Tu experiencia gastronómica online

Una propuesta web para el rubro gastronómico, pensada para presentar una pizzería, sus productos y sus diferentes opciones de menú.

## 🌐 Proyecto web

[**Explorar repositorio →**](https://github.com/lucio94cyber/PizzaHoy)

## ✨ Características

- Presentación de productos gastronómicos.
- Sección de menú y combos.
- Diseño visual atractivo.
- Organización de la información.
- Experiencia adaptable a dispositivos móviles.

## 🎯 Objetivo del proyecto

Mostrar cómo un negocio gastronómico puede fortalecer su presencia digital mediante un sitio web moderno y funcional.

## 🛠️ Tecnologías

- HTML5
- CSS3

## 📂 Sobre este repositorio

Demo de desarrollo web para una pizzería, creada como propuesta de presencia digital para el sector gastronómico.
